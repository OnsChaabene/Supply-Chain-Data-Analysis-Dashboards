# 📦 Supply Chain Data Analysis Dashboards

**Project Type:** Data Visualization & Performance Analytics  
**Bootcamp:** Google Developers Group – Data Analysis Track

---

## 🔍 Project Overview

This project focuses on analyzing a supply chain dataset to gain insights into performance, customer behavior, and sales trends. The final deliverables include three interactive dashboards:

---

### 📊 Dashboard 1: Supply Chain Overview

- Key metrics: number of products, categories, customer orders, total profit
- Customer segmentation by type (e.g., Corporate, Home Office)
- Payment method distribution
- Filter by region and year
- Map view of orders by country
- Contribution of each product category to supply flow

![image](https://github.com/user-attachments/assets/f7c3fc07-9884-421a-b430-76d8a7174998)


---

### 📦 Dashboard 2: Customer Order Tracking System

- Track all orders placed by a specific Customer ID
- View details: order date, payment type, department, shipping mode
- Visualize order origin on a map
- Shipment status comparison: scheduled vs. actual
- Color-coded shipment status (on-time, delayed)
- Breakdown of products and quantities per order

![image](https://github.com/user-attachments/assets/78925749-a9f9-4ff7-ba4b-dbdcd23601a6)


---

### 💰 Dashboard 3: Sales and Market Analysis

- Sales breakdown by customer segment
- Profit distribution across markets
- Regional and departmental sales analysis
- Yearly sales vs. target comparison
- Deep dive into 2018 sales drop due to Pacific Asia market focus

![image](https://github.com/user-attachments/assets/7f2d5441-b478-4bee-963e-9b6fee78f4e9)


---

## 🎯 Key Skills Demonstrated

- Transforming raw supply chain data into actionable insights
- Building dynamic dashboards with layered interactivity
- Detecting operational inefficiencies and market trends
- Communicating business intelligence through data storytelling
